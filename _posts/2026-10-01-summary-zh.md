## [最高法院将审理特朗普政府无保释听证拘留移民政策](https://www.nytimes.com/2026/10/01/us/politics/supreme-court-trump-migrant-detention.html) ⭐️ 8.0/10

2026 年 10 月 1 日，最高法院同意审理特朗普政府的一项政策，即拘留多年前非法越境的移民并在不举行保释听证的情况下继续关押他们。该案已在下级法院引发分歧，预计将在最高法院即将到来的开庭期进行辩论。 最高法院的裁决可能就行政部门在未经司法审查的情况下无限期拘留移民的权力范围确立长期判例，直接影响居住在美国的大量无证移民。该案还提出了关于正当程序权利以及行政与司法部门权力分立的重大问题。 该案不涉及因特定犯罪被定罪的移民，根据联邦法律的单独条款，这些人本已在驱逐程序期间可被拘留。这一争议并非个例；下级法院在特朗普政府对其他移民案件的政策重新解释上也存在分歧，而 BIA 的 Matter of Yajure-Hurtado 裁决也加剧了关于拒绝保释听证的巡回法院分歧。

rss · NYTimes Politics · Oct 1, 15:57

**背景**: 在美国移民法中，拘留通常被视为民事羁押而非刑事处罚，ICE 可以设定保释金以释放被拘留者。保释听证是一种程序，由移民法官决定被拘留者在驱逐案件进行期间是否可以保释释放。然而，如果某人的记录触发强制拘留，则无法从移民法官处获得保释听证，而特朗普政府的政策将无此类听证的拘留扩大到多年前非法越境的移民。

## [Cloudflare 征集面向 AI Agent 的下一代 Git 平台](https://blog.cloudflare.com/next-git-platform-on-cloudflare/) ⭐️ 7.0/10

Cloudflare 邀请开发者基于 Cloudflare Workers 和刚进入公开 Beta 阶段的 Artifacts 服务，构建面向 AI Agent 协作的 Git 平台，投稿截止日期为 2026 年 10 月 14 日。首名团队将获得 25,000 美元 Cloudflare 点数，参赛项目须提交 5–10 分钟演示视频、以 MIT、Apache 或 BSD 等宽松许可证发布的源代码以及运行说明。 这一举措表明业界正加速推动面向 Agent 原生的开发者工具，让 AI Agent 而非人类成为版本控制与协作流程的主要使用者。若取得成功，它可能重塑整个软件生态中代码审查、变更合并以及多 Agent 并行开发的运作方式。 Artifacts 提供可编程、兼容 Git 的版本化仓库，可大规模地以编程方式创建和 fork，其 Git 服务器以基于 Zig 的 WebAssembly 二进制形式运行在 Durable Objects 上，并可通过 Workers Bindings、REST API 和标准 Git 客户端访问。参赛者需要设计多 Agent 并行开发、代码审查、变更合并与上下文管理等功能。
